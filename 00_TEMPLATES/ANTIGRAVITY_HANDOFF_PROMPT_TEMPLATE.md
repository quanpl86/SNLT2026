# PROMPT GIAO VIỆC CHO ANTIGRAVITY

Sử dụng custom agent `hp1-lesson-project-builder`.

Bài cần triển khai: `SNLT2026-HP01-Bxx`.

1. Đọc `AGENTS.md` ở root.
2. Chỉ dùng nội dung có thẩm quyền trong `SNLT2026-HP01-Bxx/00_INPUT_FROM_CHATGPT/`.
3. Kiểm tra `MANIFEST.md`; chỉ code khi STATUS = READY_FOR_IMPLEMENTATION.
4. Chạy workflow `.agents/workflows/build_hp1_lesson.md`.
5. Xây `PROJECT_BASIC` trước, sau đó dẫn xuất `STUDENT_STARTER`.
6. Viết docs từ project thật sau khi cấu trúc/tên Node/file đã ổn định.
7. Không tự mở rộng kiến thức hoặc thay đổi student work boundary.
8. Không tuyên bố Runtime/Web PASS nếu chưa test thật.
9. Kết thúc bằng `02_QA/HANDOFF_REPORT.md` và package trong `99_RELEASE/` nếu đủ điều kiện.
