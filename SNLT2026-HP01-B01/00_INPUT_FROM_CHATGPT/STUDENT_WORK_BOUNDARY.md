# STUDENT WORK BOUNDARY — B01

## Mô hình sở hữu
### Ownership A — Học sinh tự tạo
- Sơ đồ phân tích Scene Tree.
- Mô tả vai trò các Node cốt lõi bằng lời của học sinh.
- Dự đoán trước khi chỉnh.
- Quan sát/kết quả sau khi Run.
- Quyết định giữ/hoàn tác và lý do.
- Giải thích cuối bài.

Các phần này đủ điều kiện làm MC-TK/MC-GT nếu được thực hiện cá nhân.

### Ownership B — Học sinh chỉnh sửa có ý nghĩa
- `Main/Player → Transform → Position`.
- `Main/View → Transform → Rotation`.

Các phần này chỉ được xem là MC-CN khi học sinh:
1. ghi baseline;
2. có mục tiêu/dự đoán;
3. thực hiện thay đổi;
4. Run kiểm chứng;
5. giải thích tác động.

### Ownership C — Chương trình cung cấp
- `project.godot`.
- `scripts/player.gd`.
- `scripts/view.gd`.
- Input Map.
- movement/jump.
- collision/physics.
- camera follow.
- toàn bộ platform/world baseline.
- primitive mesh/material baseline.

Ownership C KHÔNG dùng làm minh chứng năng lực cá nhân.

## Starter không được làm sẵn
- Không đặt Player X = 1.5.
- Không đặt View Y Rotation = 25°.
- Không điền sẵn hồ sơ minh chứng.
- Không cung cấp câu giải thích hoàn chỉnh trong file học sinh.

## Starter được phép cung cấp sẵn
- Project chạy được.
- Player di chuyển và nhảy.
- Camera follow.
- Level và collision.
- File phục hồi baseline.
- README thao tác mở project.
