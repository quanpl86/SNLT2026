RULES:
- Screenshot Godot luôn dùng English UI.
- Không dùng bản dịch giao diện Godot tiếng Việt làm nguồn thuật ngữ.
- Học liệu viết bằng tiếng Việt chuẩn.
- Menu, button, panel, property phải có exact English UI label khi học sinh cần tìm trên màn hình.
- Node name, file name, class, property, method, API, path và code không dịch.
- Không dịch máy móc các thuật ngữ kỹ thuật.

- Mở dự án (Import Project)

- Vị trí (Position)
- Góc xoay (Rotation)
- Chạy dự án (Run Project)
- Dừng (Stop)
- Hoàn tác (Undo)
