# Skill — Generate User Guides

## Objective
Biến project thật thành tài liệu người dùng có thể làm theo độc lập.

## Required documents
### 1. HUONG_DAN_TUONG_TAC_SAN_PHAM.md
- mục đích sản phẩm;
- cách chạy/dừng/reset;
- điều khiển;
- cách nhận biết trạng thái đúng;
- lỗi phổ biến.

### 2. HUONG_DAN_CAU_HINH_TRIEN_KHAI_DU_AN.md
- phiên bản phần mềm;
- renderer;
- cách mở/import project;
- cấu trúc thư mục;
- cấu hình kỹ thuật;
- cách test;
- cách phục hồi.

### 3. HUONG_DAN_THUC_HIEN_SAN_PHAM_STEP_BY_STEP.md
Mỗi bước quan trọng phải có:
- VIỆC EM CẦN LÀM;
- VÌ SAO;
- KIẾN THỨC ÁP DỤNG: K_NEW/K_PRIOR/HẠ TẦNG;
- KẾT QUẢ MONG ĐỢI;
- NẾU CHƯA ĐÚNG;
- MINH CHỨNG CẦN LƯU.

## Grounding rule
Không mô tả nút, Node, Scene, property, file hoặc giá trị chưa tồn tại trong project hiện tại.
Nếu có thể, tạo screenshot/crop từ chính project sau khi project ổn định.
