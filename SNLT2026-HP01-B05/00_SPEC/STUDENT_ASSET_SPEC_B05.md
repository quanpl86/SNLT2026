# STUDENT ASSET SPEC — B05 COLLECTIBLE

Sản phẩm cá nhân bắt buộc:
- 1 file `.bbmodel`;
- 1 file `.glb` export từ chính file đó;
- asset được instance trong Godot và thu thập được.

Tiêu chí tối thiểu:
1. Có ít nhất 3 phần/element có ý nghĩa hoặc cấu trúc hình học tương đương.
2. Silhouette khác placeholder/reference; chỉ đổi màu không đủ.
3. Không quá lớn/nhỏ so với Player; nếu cần điều chỉnh scale phải giải thích.
4. Hướng/origin đủ hợp lý để đặt trong scene.
5. Không yêu cầu animation.
6. Texture/material không bắt buộc.
7. Không lấy model Blockbench Gallery rồi nộp như sản phẩm cá nhân.

Minh chứng MC-3D:
- screenshot Blockbench;
- `.bbmodel`;
- `.glb`;
- screenshot GLB trong Godot;
- video runtime asset được thu;
- 1–3 câu giải thích thay đổi thiết kế và bước kiểm tra tích hợp.
